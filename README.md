# LumenRead

## What is this?

This is a focus-driven reading web application. It visually demonstrates the critical difference between static text consumption and **Magnetic Reading** when handling long-form content.

The goal of this project is to highlight the UX bottlenecks in digital reading, specifically how traditional scrolling and dense text blocks cause saccadic eye fatigue and break the user's flow state.

## How to Use the Application

1. **Paste Text**: Paste any long-form text or PDF content into the main area. The app automatically sanitizes and formats broken line breaks.
2. **Check Reading Time**: Notice the estimated reading time at the top of the screen, calculated instantly based on text length.
3. **Enable Focus Mode**: Turn on "Focus Mode". Notice how the active sentence glows brightly while the surrounding text recedes into a soft frost.
4. **Test Magnetic Scrolling**: Scroll down the page. The application will automatically snap line-by-line, keeping the current sentence perfectly centered so the eye never has to hunt for its place again.
5. **Test Auto-Read (TTS)**: Activate the audio mode. The application will read the text aloud and automatically synchronize the visual scroll and highlighting with the spoken sentence.
